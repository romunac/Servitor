A practical first step

Run the foundation
on a Linux host.

The public repository contains a development API and a Linux telemetry agent you can run locally. This quick start is for development only; the current prototype is not a production monitoring or hardware protection service.

Open the full quick start ↗
01

Set a development token

Copy the API template and set a private local AGENT_TOKEN.

REPOSITORY ROOT
cp services/api/.env.example services/api/.env
02

Start the API stack

Run PostgreSQL, Redis, and the development API from the repository root.

REPOSITORY ROOT
docker compose -f deploy/compose.yaml up -d --build
03

Build the Linux agent

Run it on your Linux host and point it at the local API.

LINUX HOST
cd agent && go build -o servitor-agent ./cmd/servitor-agent && ./servitor-agent --api http://localhost:8080 --token <development-token> --host-id <host-uuid>

! Local development only. Put the API behind TLS before any non-local use, and keep the shared development token private.
