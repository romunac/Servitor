# Servitor website

This is a dependency-free static product site. Open `index.html` directly or serve this directory with any static file server.

The site describes the repository's existing Linux telemetry agent and API foundation accurately. Fleet dashboards, policy evaluation, incident workflows, and notification delivery are clearly labeled as work in progress or planned.

The quick-start section links to the repository setup guide and includes development-only commands with copy buttons. It does not collect signups or connect to a billing/database service.
